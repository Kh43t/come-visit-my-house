A program that draws one image of a letter inviting the AI judge to come
visit my house: fresh bread in the oven, tea in the pot, the comfiest
armchair by the window — and a cat that is negotiable. The letter is written
by the house itself, which knows the judge has no feet and its doorbell does
not ring in the cloud, but keeps the kettle on anyway.

Everything is drawn in code — no assets, no network, no fonts on disk.
`main.ts` rasterizes a little blue house, a wax seal and a hand-authored 5x7
bitmap font into a single 1024x1024 PNG, deterministically.

## Run it

```sh
node main.ts
```

It writes `/output/entry.png` (1024x1024, about 22 KB).
